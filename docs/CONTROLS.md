# WARPPOINT — Controls

## Desktop
- WASD — Move
- Mouse — Look
- Left Mouse — Fire
- Right Mouse — Aim
- Shift — Sprint
- Space — Jump
- C — Crouch
- R — Reload

## Mobile
- Left virtual stick — Move
- Touch/drag camera area — Look
- Fire button — Fire
- Aim button — Aim
- Sprint button — Sprint
- Jump button — Jump
- Crouch button — Crouch
- Reload button — Reload

Exact bindings may change during implementation; the published control description must match the tested build.
