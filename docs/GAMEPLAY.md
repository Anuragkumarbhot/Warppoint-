# WARPPOINT — Gameplay

## Moment-to-Moment
Move through hostile terrain, read the environment, search for resources and react to enemy threats.

## Combat Feel
Combat should emphasize readable enemy behavior, responsive weapon feedback and meaningful resource management rather than constant enemy spawning.

## Extraction
The Warp Point is both the immediate objective and the end-state of the v0.1 vertical slice. Reaching it after surviving combat completes the prototype mission.

## Future Expansion
The same loop can support missions, larger zones, multiple enemy classes, weapon progression, vehicles and multiplayer systems.
